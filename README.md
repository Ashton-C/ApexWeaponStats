# ApexWeaponStats

Weapon stats and information for Apex Legends. Built with SvelteKit, deployed to Vercel.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy

The project uses `@sveltejs/adapter-vercel` and is configured to deploy to Vercel out of the box. Connect the repo on vercel.com and the SvelteKit framework preset will handle the rest.
